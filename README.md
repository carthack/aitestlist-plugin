# AI TestList — module remplacé / module replaced

**Français** — Ce module est remplacé par le serveur AI TestList : ajoutez l'adresse https://aitestlist.com/mcp à votre assistant IA (voir Paramètres > Intégration).
Dans Claude Code : `claude mcp add --transport http --scope user aitestlist https://aitestlist.com/mcp`, puis `/mcp` → `aitestlist` → **Authenticate**. Les commandes toutes prêtes (créer des tests, exécuter une file, rapport d'erreurs) apparaissent dans le menu `/`.
Pour retirer l'ancien module : `/plugin uninstall aitest@aitestlist-plugin`.

**English** — This module is replaced by the AI TestList server: add the address https://aitestlist.com/mcp to your AI assistant (see Settings > Integration).
In Claude Code: `claude mcp add --transport http --scope user aitestlist https://aitestlist.com/mcp`, then `/mcp` → `aitestlist` → **Authenticate**. The ready-made commands (create tests, run a queue, error report) appear in the `/` menu.
To remove the old module: `/plugin uninstall aitest@aitestlist-plugin`.
